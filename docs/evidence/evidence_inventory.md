## SHAP Plot Descriptions

### shap_summary.png (beeswarm)
- 100 test samples, top 12 features displayed
- Top features by impact: loan_amnt, installment, term_36 months, total_rec_int, annual_inc, revol_util, inq_last_6mths
- loan_amnt: high value = strong positive SHAP (higher loan amount predicts higher rate)
- installment: high value = strong negative SHAP (collinear with loan_amnt; counterbalances when term is short)
- term_36 months: negative SHAP (36-month loans predict lower rates than 60-month loans)

### shap_waterfall.png (single prediction)
- Shows feature-level attribution for a single test record
- Base value represents average model output across training data
- Each feature's SHAP value shows its contribution pushing prediction above or below base

### shap_bar.png (mean absolute impact)
- Global summary: loan_amnt is the dominant feature overall
- installment is second; both are loan size signals
- term_36months is third; captures loan duration risk pricing
